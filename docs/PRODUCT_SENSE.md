# ClipFlow — 제품 정체성 (v2, 2026-05-31)

> v1 → v2 재정의 배경: 블로그 영역이 dailyget·haruzine으로 분리 운영되면서
> ClipFlow는 **유튜브 영상 자동 제작 SaaS**로 정체성 좁힘.
> 이전 버전은 `docs/PRODUCT_SENSE.v1-2026-04.md` 보관.

---

## 한 줄 정의

> **ClipFlow는 유튜브 하고 싶지만 시간·편집 능력 때문에 시작 못 한 초보 1인 크리에이터가,
> 주제 한 줄만 던지면 30초 만에 대본·영상·썸네일이 나오고 매일 자동 업로드되는 SaaS다.**

이 문장에 안 맞는 모든 기능·페이지·API는 정리 대상.

---

## 타깃 사용자 (페르소나)

| 항목 | 내용 |
|---|---|
| **누구** | 유튜브 시작하려는 1인 초보 (구독 0~1만) |
| **상황** | 영상 편집 처음 · 대본 막막 · 본업 따로 있음 |
| **나이대** | 30대 부업러 + 40~50대 비개발자까지 광범위 |
| **고통** | **시간 → 꾸준함 붕괴.** 영상 1편에 5~10시간이라 일주일 하다 멈춤 |
| **현재 대안** | CapCut/Vrew로 직접 편집 / 외주 / 그냥 포기 |

→ 한 사람을 떠올린다면 **"유튜브 채널 만들고 첫 영상도 못 올리고 멈춘, 평일 본업 끝나면 1시간 남는 직장인"**.

---

## 핵심 가치 (3가지 자동화)

ClipFlow가 사용자에게 약속하는 것:

1. **대본 자동** — 주제 한 줄 → AI가 30초 만에 대본 완성
2. **영상 자동** — 대본 → Remotion으로 영상·자막·BGM 자동 렌더
3. **매일 자동 업로드** — 한 번 셋업 → YouTube에 매일 새벽 자동 업로드

> 사용자 경험: "주제만 던지면 자고 일어나면 영상이 올라가 있다."

---

## 의도적으로 안 하는 것 (Q4 답: e = 모두 정리)

ClipFlow가 **하지 않는 영역**. 코드 정리 기준:

- ❌ **블로그 자동화** — dailyget·haruzine이 이미 함 → 24개 API 제거
- ❌ **복잡한 SEO 분석** (네이버 검색량·트렌드·발행량 등) — 5개 API 제거
- ❌ **미디어허브·여행 리서치** 같은 부가 기능 — 4개 API 제거
- ❌ **다국어 지원** — 한국 시장만, 일·영문은 v2 이후
- ❌ **에이전시·대량 처리** — 1인 사용자에만 집중

→ **약 33개 API + 관련 페이지·wiki 폴더 정리 예정 (Phase 2)**.

## 가격 모델 (Q5 v2: 결제 인프라 X · BYOK · R2 보관비만, 2026-05-31)

> 형님 결정 (2026-05-31): "결제 인프라 구축 하지마라. 유튜브 가입으로 가격 책정 가능.
> AI API는 본인들의 키를 쓰게 할 거니 나는 R2 보관비만 책정하면 될 것 같다."

### 핵심 원칙

1. **결제 인프라 0** — PortOne·토스·Stripe 모두 v1 제외. **출시 부담 -3~6개월.**
2. **BYOK (Bring Your Own Key)** — 사용자가 본인 AI 키(Anthropic·Gemini·OpenAI 중 1개) 등록
   → ClipFlow는 AI 호출 비용 0. 사용자가 본인 사용량 제어.
3. **R2 보관비만 책정** — 형님 실제 부담하는 비용 = Cloudflare R2 저장료 (영상·자막·썸네일)
4. **YouTube 자동 업로드 = 선택 옵션** (Q7 답: ON/OFF 토글)

### 단계 (v1 출시 — 매우 단순)

| 단계 | 한도 | 가격 |
|---|---|---|
| **무료 (모든 가입자)** | 월 3편 · ClipFlow 워터마크 · 30초 · 다운로드만 · BYOK | **0원** |
| **확장 (YouTube Premium 또는 ClipFlow 후원자)** | 무제한 · 워터마크 제거 · 자동 업로드 · 5분 | **0원** (조건부) |
| **R2 추가 저장** (선택) | 200편 초과 시 추가 슬롯 | v2에서 결정 |

→ **v1은 매출 0원 OK.** 사용자 1,000명 모으기에 집중. 매출화는 v2에서 별도 결정.

### 비용 책임 분담

| 항목 | 누가 부담 | 한도 |
|---|---|---|
| **AI 호출 (대본·이미지)** | 사용자 (본인 키) | 사용자 키 한도 |
| **Remotion 렌더** | 형님 (NAS·Railway) | 4인 이하 무료 라이선스 |
| **R2 영상 저장** | **형님 (Cloudflare R2)** | 10GB 무료 → 200편/사용자 권장 |
| **YouTube 업로드** | 형님 (인프라) + 사용자 (OAuth) | YouTube 일일 한도 |

### "YouTube 가입으로 가격 책정" 검증 메커니즘 (3가지 후보)

| 옵션 | 방식 | 장단점 |
|---|---|---|
| **A. ClipFlow 채널 구독** | 사용자가 ClipFlow YouTube 채널 구독 → OAuth로 확인 | 단순·즉시 검증 가능 / 구독 해지 시 무료 회수 어려움 |
| **B. YouTube 채널 연결만** | YouTube 채널 OAuth 연결 = 자동 업로드 권한 = "확장" | 구현 가장 쉬움 / Premium 여부 무관 |
| **C. YouTube Premium API** | YouTube Data API로 Premium 멤버 확인 | 구현 어려움 (개인정보 권한) / 가장 명확 |

→ **v1 권장: B** (YouTube 채널 OAuth = 확장 자동 활성화). 사용자에게 "YouTube 자동 업로드 켜기" 토글 = 확장 모드.

### Remotion 비용 재계산 (BYOK 후)

- 1인 운영 = 무료 라이선스 (4인 이하)
- **자동 렌더 $0.01/render or $100/월**:
  - 1,000명 사용자 × 월 3편 무료 한도 = 월 3,000편
  - 3,000 × $0.01 = **월 $30 (약 4.2만원)**
- → Remotion 비용은 사용자 1,000명까진 부담 가능 수준. **R2 저장이 진짜 변수.**

### R2 비용 계산 (형님 진짜 부담)

- 영상 1편 평균 ~50MB (30초 720p)
- 1,000명 × 월 3편 × 50MB = **월 150GB**
- R2 가격: 10GB 무료 + 이후 $0.015/GB·월 = **월 ($150 - $10 + $0.015 ×140) = 약 $12 (1.7만원)**
- → **월 약 6만원 (Remotion + R2)** = 매출 0이라도 형님 인프라 6만원으로 1,000명 운영 가능

### v2 (매출화) 후보 — 1,000명 확보 후 결정

- 옵션 a: R2 추가 저장 무제한 = 월 1,000원
- 옵션 b: 워터마크 제거 = 월 3,000원
- 옵션 c: 스폰서십·광고 후원 (영상 엔딩 카드)
- 옵션 d: 그대로 무료 + 인프라 기부 (오픈소스 형식)

→ **v1 KPI = 가입 1,000명. 매출 KPI = v2에서.**
